Module policy_gate 

Expand description

Fail-closed external policy gate for agent shell commands (fork-only).

When [runtime] policy_gate names an argv, every shell command a runtime adapter builds is first offered to that program. The gate receives one JSON document on stdin:

{"tool_name":"bash","tool_input":{"command":"<full command string>"}}

Exit status 0 allows the command. Every other outcome refuses it: a non-zero exit, death by signal, a spawn failure (including a missing binary), or running past POLICY_GATE_TIMEOUT. A refusal is returned as an error from the build_shell_command* call, so the caller never gets a process to spawn and there is no path that runs the command anyway.

The gate is applied by wrapping the runtime adapter in PolicyGatedRuntime inside super::create_runtime_with_path, so the shell tool, cron shell jobs, skill shell tools, the coding-CLI executor, and delegates (which share the parent’s runtime) all pass through it.
