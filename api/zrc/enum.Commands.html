Quickstart

Quickstart — create one working agent end-to-end. Replaces the section-by-section onboarding flow with a single preset-driven path. Interactive: the flags below pre-seed checklist selectors but do not skip them; a terminal is required.

Fields

§model_provider: Option<String>

Provider type (anthropic / openai / openrouter / ollama).

§model: Option<String>

Model id for the new provider entry.

§api_key: Option<String>

API key for the new provider entry (omit for ollama / local).

§agent: Option<String>

Alias for the new agent. Defaults to a sanitized provider name.

§

Onboard

Deprecated. Use zeroclaw quickstart. Any flags error.

Fields

§section: Option<Section>

Configure a specific section only. Omit to run the full flow.

§quick: bool

Skip interactive prompts; read from –api-key/–model-provider/–model/–memory.

§cli: bool

Force the dialoguer CLI backend instead of the default ratatui TUI.

§tui: bool

Deprecated: TUI is now the default. Accepted as a no-op for one release.

§force: bool

Don’t ask “keep stored secret?” — always re-prompt.

§reinit: bool

Back up existing config and start from defaults.

§api_key: Option<String>

API key for model_provider configuration.

§model_provider: Option<String>

ModelProvider name. Used as the type key for the synthesized [providers.models.<type>.default] entry.

§model: Option<String>

Model ID override.

§memory: Option<String>

Memory backend (sqlite, lucid, markdown, none).

§channels_only: bool
§providers_only: bool
§memory_only: bool
§hardware_only: bool
§tunnel_only: bool

Daemon

Start long-running autonomous runtime (gateway + channels + heartbeat + scheduler)

Fields

§port: Option<u16>

Port to listen on (use 0 for random available port); defaults to config gateway.port

§host: Option<String>

Host to bind to; defaults to config gateway.host

§ephemeral: bool

Self-terminate after all socket clients disconnect (with grace period)

§allow_degraded_security: bool

Boot even when security-critical config sections were dropped to their defaults during load. Without this, the daemon refuses to start with a weakened posture; with it, the daemon boots so the operator can reach repair surfaces, emitting a repeating warning.
